## 1. 本批目标（DoD）

交付一个可运行的最小 Wiki 内核：

1. **旗标**可开/关（默认 **开**）：`wiki_enabled`、`wiki_compile_on_ingest`  
2. **磁盘** `data/wiki/materials|chemicals/*.md` + SQLite `wiki_pages`  
3. **只读 API** 列表/详情  
4. **入库后异步编译**：从 SourceGuide / chunk chem meta / `kb_products` 合并材料/化学品页，带 `source_ids`  
5. **旗标全关**时：ingest/chat/DOE **行为与现网完全一致**（W3/W4 未做，chat/DOE 本批不改）

**非本批：** Chat 双轨、DOE 约束导出、Lint 主编、机理/避坑专题、Wiki 可视化编辑器、Neo4j 投影。

## 2. 数据契约

### 2.1 Markdown 页

路径（相对 DB 目录旁 `data/wiki/`）：

```text
data/wiki/
  materials/{norm_key}.md
  chemicals/{cas_or_hash}.md
```

Front-matter（YAML）：

```yaml
---
kind: material | chemical
title: E-51
entity_id: material:e51   # or chem:cas:25068-38-6
norm_key: e51
source_ids: ["uuid-a", "uuid-b"]
flags: []                 # e.g. conflict, stale, human_locked
updated_at: 2026-09-09T12:00:00Z
---

# E-51

## Summary
...

## Evidence
### Source `{source_id}`
- trade_name / CAS / notes from guide or chunk meta
```

### 2.2 SQLite `wiki_pages`

| 列 | 类型 | 说明 |
|----|------|------|
| id | str PK | uuid |
| path | str unique | 相对 `wiki/` 如 `materials/e51.md` |
| kind | str | material / chemical |
| entity_id | str nullable | 对齐 KG/材料 |
| title | str | |
| norm_key | str index | |
| content_hash | str | 正文 hash，幂等 |
| source_ids | JSON | |
| flags | JSON | |
| updated_at | datetime | |
| revision | int | 自增 |

Alembic `0025_wiki_pages` + 模型挂 `Base`（非 prod `create_all` 覆盖测试）。

## 3. 切片明细

### W0 — 旗标（默认开）

| 项 | 值 |
|----|-----|
| `wiki_enabled` | `True` — 总开关（API/编译） |
| `wiki_compile_on_ingest` | `True` — ingest 成功后 enqueue |
| `wiki_chat_blend` | `False` — **预留** W3，本批不读 |
| `wiki_doe_constraints` | `False` — **预留** W4 |

落点：`config.py` · `env_flags.py`（category `kb`）  
环境变量：`FORMUMIND_WIKI_*`

### W1 — Store + API

| 模块 | 职责 |
|------|------|
| `db/models.py` | `WikiPage` |
| `db/wiki_store.py` | `upsert_page` / `get` / `list` / `resolve_root` |
| `services/wiki/schema.py` | front-matter parse/dump · path builders |
| `services/wiki/paths.py` | `wiki_root()` beside sqlite file |
| `api/wiki.py` | `GET /api/wiki/pages` · `GET /api/wiki/pages/{id}` · `GET /api/wiki/by-path` |
| `main.py` | `include_router` |

**API 行为：** `wiki_enabled=False` → 409「Wiki 未启用」。

### W2 — Compiler + dispatch

| 模块 | 职责 |
|------|------|
| `services/wiki/compile.py` | `compile_source(source_id) -> dict` |
| `worker/tasks.py` | `run_wiki_compile_task` · `dispatch_wiki_compile(source_id)` |
| `kb_index.index_source` | `n>0` 且两旗标开 → `dispatch_wiki_compile(source_id)` |

**Compile 算法（确定性优先，LLM 可选增强）：**

1. 读 `SourceDocument` + `get_source_guide`（可空）+ chunks（`meta.chem` / products）  
2. 收集候选：  
   - guide.`products` → material pages  
   - chunk products / `kb_products` 提及该 source → material  
   - CAS 型 chem → chemical pages  
3. 对每个候选 `norm_key`：  
   - 若页不存在：建 stub + Summary  
   - 若存在：`source_ids` 并集；在 `## Evidence` 下追加本 source 段（已存在同 source 段则跳过）  
4. 写盘 + `wiki_pages` upsert（hash 变则 `revision+=1`）  
5. **本批不做 LLM 长文重写**（避免成本/幻觉）；结构化合并且人类可读即可。预留 `wiki_llm_rewrite` 旗标默认关。

**幂等：** 同一 `source_id` 重复 compile 不复制 Evidence 段。

## 5. 红线

1. 不改 chat / DOE / recommend 检索路径（W3/W4）。  
2. 不删除 / 改写 `document_chunks`。  
3. Compile 失败只打日志，**不**让 `index_source` 失败。  
4. 异步任务；eager 模式用 daemon thread（同 kb_ingest）。  
5. 路径穿越防护：`norm_key` 只允许 `[a-zA-Z0-9._-]`。
