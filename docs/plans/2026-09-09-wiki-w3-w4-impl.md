## 3. 数据契约增量

### 3.1 Front-matter 扩展（材料 / 体系 / 避坑）

```yaml
---
kind: material | chemical | system | mechanism | pitfall
bounds:                    # DOE 用
  - name: catalyst_wt
    min: 0.1
    max: 1.5
    unit: wt%
forbidden:                 # 禁区文案
  - "催化剂 >1.5 wt%"
---
```

`compile_source`：从 `SourceGuide.parameter_space` 写入/合并对应 `systems/{domain}.md` 或材料页 `bounds`；FAQ 中含「避免/禁忌」→ `pitfalls/`；summary 机理句 → `mechanisms/`（确定性规则，本批不做 LLM 长文）。

### 3.2 Lint flags

页级 `flags` 可含：`stale`（无 source_ids）、`orphan`（entity 无 chunk 提及，尽力）、`conflict`（同名 bound 区间不相交）。

## 4. 切片明细

### W3 — Chat 双轨

| 模块 | 职责 |
|------|------|
| `services/wiki/retrieve.py` | `search_wiki(q, k)`：title/norm_key/正文关键字；返回 snippet + path |
| `api/chat.py` `_augment_with_kb` | `wiki_chat_blend` → 前置/并入 Wiki Evidence（`source=wiki`, `identifier=wiki:{path}`） |
| `_stream_answer_plan` | 同构 blend |
| `llm._chat_prompt` | 分段标注「Wiki 编译结论」vs「原始摘录」 |
| `chat_claims` 调用点 | 过滤掉 `source==wiki` / `identifier` 前缀 `wiki:` |

**验收：** 旗标关 = 基线；开 = 上下文含 Wiki 标题，citations/claims 仍来自 chunk。

### W4a — DOE 约束

| 模块 | 职责 |
|------|------|
| `services/wiki/constraints.py` | `wiki_parameter_bounds()` / `wiki_forbidden()` |
| `factor_suggest.suggest_factors` | 命中则收紧 `low`/`high`，`source` 含 `wiki`，evidence_ids=`wiki:path` |
| `kb_index.doe_parameter_hints` | 追加 Wiki 提示行（或 wiki helper） |
| `compile.py` | 写入 bounds / systems / pitfalls / mechanisms |

**验收：** 有禁区页时 suggest 区间被裁；无 Wiki / 旗标关与现网一致。

### W4b — Lint

| 模块 | 职责 |
|------|------|
| `services/wiki/lint.py` | `lint_page` / `lint_all` |
| `dispatch` after compile | 若 `wiki_lint_on_compile` |
| `GET /api/wiki/flags` | 列出带 flags 的页 |

### W4c — 只读浏览器

| 模块 | 职责 |
|------|------|
| `frontend` WikiPanel / Modal | 调现有 `/api/wiki/*`；设置或资料侧入口 |
| API 客户端 | `api.listWikiPages` 等 |

### W4d — Neo4j 薄投影（可选）

| 模块 | 职责 |
|------|------|
| `services/wiki/neo4j_project.py` | 仅当 `wiki_neo4j_project && neo4j_enabled`：`upsert_compound(uid=entity_id)` |
| compile 末尾 best-effort | 失败只打日志 |
