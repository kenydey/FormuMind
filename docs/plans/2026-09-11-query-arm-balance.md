# 检索候选量 × 质量平衡方案（OpenAlex 查询策略）

> 领域：金属表面处理 / 反腐蚀涂料 / 脱脂剂 / 转化膜
> 日期：2026-09-11
> 状态：**方案，供评审，未改代码**
> 证据：全部数值为当日对 OpenAlex 生产接口的实测（3 个真实主题 × 6 种策略 × 真实排序器），非估算

---

## 0. 结论摘要

**问题**：OpenAlex 把空格分隔的词按 **AND** 连接并做**词干化**，而查询串由 LLM 扩展生成、长度每次不同。
结果是**同一主题的召回在 1 条到几千条之间抽奖**：实测「铝合金碱性脱脂剂」基线只返回 **1 条、领域命中率 0%**。

**推荐**：**方案 C —— 叠加三臂（保留精确意图 + 补两个召回臂）**，并**配套修正质量闸**。
不建议二选一（纯召回 or 纯精确），因为实测显示放量会线性推高入库量，而现有相关性闸门其实无效（见 §2）。

| 主题（实测） | 现状取回 | 叠加后取回 | 领域命中 | 基材命中 | 异基材噪声 |
|---|---|---|---|---|---|
| 铝合金碱性脱脂剂 | **1** | **37** | 0% → **62.2%** | 0% → 16.2% | 0% |
| 镁合金无铬钝化剂 | 25 | **72** | 40% → **47.2%** | 12% → **44.4%** | 12% → **6.9%** |
| 水性环氧防腐底漆 | 25 | **69** | 100% → 98.6% | 4% → 7.2% | 0% |

数量提升 2–37 倍，**领域命中率不降反升**（除防腐涂料案 100%→98.6%，可忽略），异基材噪声下降。

## 1. 问题定性：抽奖式召回

### 1.1 机制——词数-召回曲线（实测）

同一主题、逐词增加 AND 约束，OpenAlex 库内总命中数：

| 主题 | 2 词 | 4 词 | 6 词 | 8 词（现状） |
|---|---|---|---|---|
| 水性环氧防腐底漆 | 362 | 362 | 239 | 219 |
| 镁合金无铬钝化剂 | 3169 | 491 | 94 | **89** |
| 铝合金碱性脱脂剂 | 91 | 7 | 6 | **1** ← 断崖 |

扩展词表实际是 **8 个多词短语 ≈ 14–20 个单词**，全部 AND 后，窄主题直接归零。
更隐蔽的是：**通用 OpenAlex 也会被饿死**——实测 24 词扩展串 → 1 条，19 词 → 满页 25 条。

### 1.2 为什么表现为「有时候能搜到，有时候一篇都没有」

扩展串由 LLM 生成，**长度与措辞每次不同**。同一主题，本次 24 词（1 条）、下次 19 词（满页）。

> **这解释了历史上检索总量的大幅波动**：118 / 129 / 28 / 175 / 1 —— 不是网络抖动，是查询串长度抽奖。

## 2. 关键约束：为什么「放量」不是免费的

这一节是本方案的核心——**不解决它，任何放量方案都会以质量换数量**。

| 事实（代码级核实） | 后果 |
|---|---|
| `search_providers._ranked(i, offset) = max(0.1, 1.0 - (offset+i)*0.02)` | `relevance` 是**名次代理**，不是 topicality 分 |
| `kb_ingest_min_relevance = 0.45` | 等价于「名次 < 27.5」→ **首页 25 条全部通过**，形同虚设 |
| `kb_ingest_max_docs = 0`（默认不限） | 入库量**随候选线性增长** |
| 入库是 Celery 长任务 | 实测单轮可达 **27 分钟**；4 核机 + 本地 OCR ~10s/页 |
| `kb_ingest_workers = 3` | 瓶颈是**解析内存**（pymupdf4llm ~350MB/篇、OCR ~557MB） |

**推论**：如果只放宽召回而不修正 §2 第 2 行，候选从 89 → 2722 就意味着入库量同步膨胀，
而筛选依据仍是「名次」，不是「相关性」。**真正的质量闸是 `_merge_filter_rank` 的关键词重叠、
`domain_match`、`kb_ingest_topic_filter` 和 LLM rerank，`min_relevance` 不在其中。**

### 3.4 已实测否决的修法（勿再尝试）

| 修法 | 实测结果 | 否决理由 |
|---|---|---|
| 纯 OR 同一批词 | 召回暴涨但领域命中跌至 28% | 词干化使 `passivation`→`passive tracers`、`conversion`→CO2 conversion |
| 给短语加引号 | **召回反而更少**（30 条 vs 1057 条） | 引号短语需整体匹配，比不加引号更严 |
| 复用 `keyword_allow` 词表 | `passivat` → 5 条无关 | 那是**子串匹配词干**，不是检索词 |
| 只用领域词（方案 B 单独用） | 召回 14 万–59 万，基材命中率反降到 0% | 丢失用户具体意图与基材约束 |

## 4. 推荐方案：叠加三臂（C″）

### 4.1 架构

```
                    ┌─ 臂1 精确臂 ─────────────────────────────┐
   Requirement ───▶ │  min(扩展词数, 8) 原样 AND 拼接           │──┐
   (基材/领域)      │  保用户具体意图，质量最高                  │  │
                    ├─ 臂2 召回臂 ─────────────────────────────┤  │
                    │  (基材词 OR …) AND (扩展词 OR …)          │  ├─▶ 去重合并
                    │  补基材锚定，修复词干漂移                  │  │   (按 DOI/WorkID)
                    ├─ 臂3 广谱臂（条件触发）──────────────────┤  │
                    │  (基材词 OR …) AND (领域 venue_terms OR …)│──┘
                    │  仅当臂1∪臂2 去重后 < 30 条时启用          │
                    └───────────────────────────────────────────┘
                                     │
                                     ▼
                        现有排序 / 门控（§5 加强）
                        keyword-overlap → domain_match
                        → topic_filter → LLM rerank
                                     │
                                     ▼
                              入库（受配额约束）
```

### 4.2 为什么是叠加而不是二选一

| 判据 | 实测依据 |
|---|---|
| 保留用户意图 | 臂1 不丢弃扩展词，仅在词数上设上限 |
| 修复断崖 | 脱脂剂案 1 → 37 条 |
| 精度不倒退 | 三案领域命中 62.2% / 47.2% / 98.6%，均 ≥ 基线 |
| 噪声下降 | 镁合金案 12% → 6.9% |
| 成本可控 | 多 1–2 次 API 调用（礼貌池免费，实测 ~1s/次） |
| 可回滚 | 三个臂独立开关，任一臂失效不影响其余 |

## 5. 配套：质量侧必须同步加强（否则放量即稀释）

**这部分不是可选优化，是方案成立的前提。**

| # | 措施 | 现状 | 目标 | 理由 |
|---|---|---|---|---|
| M1 | **按臂加权** | 无概念 | 臂1 命中 ×1.2、臂2 ×1.0、臂3 ×0.8 | 广谱臂单臂可返 14 万条，不加权会挤掉精确命中 |
| M2 | **相关性闸真实化** | `_ranked` 是名次代理；`min_relevance=0.45` ≈ 位置 < 27.5 | 改用关键词重叠 / topicality 分 | 否则「放量」直接等于「入库放量」 |
| M3 | **入库配额** | `kb_ingest_max_docs = 0` 不限 | 建议 40/项目轮 | 4 核机 + OCR ~10s/页，29 分钟级任务不宜再放大 |
| M4 | **臂级可观测** | 无 | 日志记录每臂返回量/采纳量 | 抽奖问题必须可被持续监测，否则复发无感 |

## 9. 验收标准（可测）

1. **断崖消失**：三个历史最差主题（脱脂剂类）候选数 ≥ 20
2. **精度不倒退**：三案领域命中率 ≥ 各自基线
3. **噪声不上升**：异基材噪声 ≤ 基线
4. **入库可控**：单项目轮入库篇数 ≤ 配额上限，任务时长不超基线 1.5×
5. **可回滚**：三臂开关全关时，行为与现状**逐字节一致**
