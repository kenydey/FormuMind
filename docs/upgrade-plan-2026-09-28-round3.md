## 方案：5 波

### Wave 0 — 设置页重组（约 2–3 人天，先行）
**背景**：设置页现有 11 个 tab（大模型 / API 配置 / Skills / MCP / 记忆 / 项目 / 环境变量 / 推荐 / NotebookLM / 组织看板 / 依赖管理），其中"记忆""项目"是新增的，页面已凌乱。

**必要性评估**：

| Tab | 评估 | 结论 |
|-----|------|------|
| 项目 | 92 行，内容只有一个 `agent_context` 输入框；且只在"有活跃项目"时有意义，却放在全局设置里，心智错位 | **取消独立 tab**，搬到项目切换/管理入口旁（无项目时不显示） |
| 记忆 | 有必要——Agent 记忆影响回答，用户需要可查、可搜、可删；不透明记忆 = 不可控行为 | **保留功能，搬家**：它是数据管理不是设置，搬到知识库（Knowledge Hub）做"记忆"区 |
| 组织看板 | `OrganizationDashboard` 只在 SettingsModal 里挂载；看板是"看"的地方 | **搬出设置**，给独立入口（或暂时收进"高级"） |
| 大模型 + API 配置 | llm tab 自己写"也可在 API 配置 Tab 统一管理"，拆分是人为的 | 合并为"模型与 API" |
| Skills + MCP | Cheng 早定的统一 Skills + MCP 方向 | 合并为"Skills 与连接"（NotebookLM 是登录态外部连接，一并归入） |
| 推荐 | 内容本就是杂项偏好（配方模式、Wiki 问答模式、解析配置、OCSR） | 改名"偏好" |
| 环境变量 + 依赖管理 | 低频、高风险操作 | 合并为"高级" |

**重组结果**：11 tab → 4 tab（模型与 API / Skills 与连接 / 偏好 / 高级）；项目→项目入口，记忆→知识库，组织看板→独立入口。

**注意**：`settingsTab` 持久化在 store 中，旧 tab id（memory/project/org 等）需做映射或默认回退，避免升级后白屏/空 tab；相关测试（SettingsModal/MemoryPanel/ProjectSettingsPanel）同步迁移。

### Wave 1 — Agentic 迭代检索（约 8–10 人天）
**目标**：把 PaperQA2 最核心的差异做出来——不是一次查完，而是"查 → 看缺什么 → 换词再查"的循环。

1. 新增 `agent_search_loop`：每轮检索后做缺口评估（问题分面覆盖率，启发式先行），未覆盖的分面改写查询再查；跨轮去重；迭代上限 + token/时间预算硬 guard。
2. 缺口评估先用确定性规则（分面关键词命中），LLM 评估作为可选项（默认关，成本）。
3. 在 golden 集上 A/B：单发 vs 迭代，指标用 coverage 提升 + 引用增量，代价是检索次数。
4. fail-open：任何一轮失败不影响已有证据，预算耗尽即停。

### Wave 2 — 证据可观测性（约 3–4 人天）
**目标**：让第二轮的改动可被度量，否则等于没做。

1. tier2：触发率、压缩前后 token、LLM 调用次数 → 结构化日志 + `/api/ops/evidence-stats` 轻量接口。
2. DOE 闭环：每轮 cycle 的测量数、收敛轮数、BayBE/LHS 路径选择 → cycle 记录里已有字段，前端 LoopModal 加一个"循环统计"小节展示。
3. 不做重监控体系：日志 + 一个接口 + 前端一小节，够用即可。

### Wave 3 — 对抗性 golden（约 4–5 人天）
**目标**：门禁从没红过是风险，不是成绩。

1. 新增 10–15 组对抗用例：无好答案的问题（应拒答或低覆盖）、数字陷阱（单位换算、量级）、矛盾来源（两篇文献结论冲突）。
2. 扩展 rigor_rubric：`abstention_correctness`（该拒答时是否拒答）、`contradiction_flagged`（矛盾是否被标出而非和稀泥）。
3. 预期：这批用例当前系统大概率部分失败——失败是正常的，门禁第一次有真正的信号。修不修得看失败分析，不硬凑全绿。

### Wave 4 — 向量检索规模天花板评估（约 2–3 人天）
**目标**：用实测数字决定迁不迁移，而不是拍脑袋。

1. 压测：构造 10k/50k/100k chunk 规模，测进程内 cosine 的召回延迟与内存，画出曲线。
2. 决策文档：撑得住 → 维持现状，写下天花板数字和监控点；撑不住 → 给出迁移方案（不含实施）。
3. 本波只出数字和决策，不做迁移。
